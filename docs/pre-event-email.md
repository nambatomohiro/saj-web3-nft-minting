────────────────────────────────
1. ターミナル（コマンドライン）を開く
────────────────────────────────

これから先の作業は、すべて「ターミナル」と呼ばれる黒い画面で行います。まず開き方です。

【Windows】
  スタートボタンを押し、「PowerShell」と入力
  → 表示された「Windows PowerShell」を開く

【Mac】
  Command + スペースキーを押し、「ターミナル」と入力
  → Enter

画面が開き、行の先頭または末尾に「>」「%」「$」のいずれかの記号が表示されていれば成功です。
これは「入力待ち」を表す印で、記号そのものを打ち込む必要はありません。

以降、このメールで「実行してください」と書いてあるものは、
コマンドをこの画面に貼り付けて Enter を押す、という意味です。


────────────────────────────────
2. Git をインストールする
────────────────────────────────

リポジトリ（教材一式）を取得するためのソフトです。

【Windows】
  https://git-scm.com/download/win
  上記からインストーラをダウンロードして起動してください。
  設定項目がいくつも表示されますが、すべて既定のまま「Next」で問題ありません。
  インストール後、PowerShell を一度閉じて開き直してください。
  （開いたままだと、インストールした Git を認識しません）

【Mac】
  下の確認コマンドを実行すると、多くの場合
  「"git" コマンドを実行するには、コマンドラインデベロッパツールが必要です」
  というダイアログが表示されます。「インストール」を押して完了までお待ちください。
  ダイアログが出ない場合はこちらから: https://git-scm.com/download/mac

▼確認
  git --version

  → 「git version 2.39.0」のようにバージョンが表示されれば成功です。


────────────────────────────────
3. Docker Desktop をインストールする
────────────────────────────────

教材の実行環境です。これを入れておけば、当日その場でのインストール作業は発生しません。

  https://www.docker.com/products/docker-desktop/

【Windows】
  「Download for Windows」からインストーラを取得してください。
  WSL2 に関する項目はチェックを入れたまま進めます。
  インストール完了後、PC の再起動が必要です。

【Mac】
  Apple Silicon 版と Intel 版があるので、お使いの Mac に合う方を選びます。
  見分け方: 画面左上のリンゴマーク →「このMacについて」
    「チップ」に Apple M1 / M2 / M3 などと記載 → Apple Silicon 版
    「プロセッサ」に Intel と記載            → Intel 版

インストールが終わったら Docker Desktop を起動し、
クジラのアイコンの状態が「Running」（緑）になるまでお待ちください。
ここが Running になっていないと、以降のコマンドはすべて失敗します。

▼確認（ターミナルを開き直してから実行してください）
  docker --version
  docker compose version

  → 両方ともバージョンが表示されれば成功です。


────────────────────────────────
4. 教材を取得し、プロジェクトフォルダへ移動する
────────────────────────────────

ターミナルには「いまどのフォルダで作業しているか」という現在地があります。
これを「カレントディレクトリ」と呼びます。
手順5以降のコマンドは、すべてこれから取得するプロジェクトフォルダの中で実行します。
現在地が違うと、まったく同じコマンドでもエラーになります。

▼(1) 置き場所へ移動する（ホームフォルダの直下に置きます）

  cd $HOME

▼(2) 教材を取得し、そのフォルダの中へ入る

  git clone https://github.com/nambatomohiro/saj-web3-nft-minting.git
  cd saj-web3-nft-minting

▼(3) 現在地を確認する

  pwd

  → 表示された行の末尾が「saj-web3-nft-minting」になっていれば、正しい場所にいます。

★ここが最重要ポイントです
  ・これ以降のコマンドは、すべてこのフォルダの中で実行してください。
  ・ターミナルを閉じて開き直すと、現在地は元に戻ります。次回作業するときは
    cd $HOME → cd saj-web3-nft-minting で戻ってから始めてください。
  ・うまくいかないときは、まず pwd で現在地を確認してください。

▼(4) 実行に必要なデータを事前にダウンロードする

  docker compose pull

  数分から十数分かかることがあります。
  会場の Wi-Fi に頼らずに済むよう、必ず事前に実行しておいてください。


────────────────────────────────
5. 起動確認
────────────────────────────────

プロジェクトフォルダにいることを確認してから、実行してください。

  docker compose up

▼成功の目印
  Started HTTP and WebSocket JSON-RPC server at http://0.0.0.0:8545/

この行と、テスト用アカウントが20個表示されれば成功です。
確認できたら Control + C キーで停止してください。
（Mac の方も Command ではなく Control キーです）


────────────────────────────────
6. ウォレットの準備と秘密鍵の設定
────────────────────────────────

当日は公開テストネット（Polygon Amoy）にも記録します。そのための準備です。

▼(1) MetaMask をインストールする

  https://metamask.io/

▼(2) セミナー専用ウォレットを用意する

  ★普段お使いのウォレット・秘密鍵は絶対に使わないでください。
   練習の都合で秘密鍵をファイルに書き込むため、使い捨て前提のウォレットを使います。

  【MetaMask を初めて入れる方】
    インストール後の案内どおりに「新しいウォレットを作成」してください。
    それがそのままセミナー専用ウォレットになります。追加の作業は不要です。

  【すでに MetaMask を資産の入った状態でお使いの方】
    推奨:
      ブラウザで新しいプロファイルを作成し、そちらに MetaMask をインストールして
      新規ウォレットを作成してください。普段使いと完全に分離できます。
    最低ライン:
      いま使っている MetaMask で「アカウントを追加」し、セミナー専用のアカウントを
      1つ作成してください。この場合、以降の提出・設定には必ずその新しいアカウントの
      アドレスと秘密鍵を使ってください。

  ★どちらの場合も、シークレットリカバリーフレーズ（12単語）は
   絶対に開かない・コピーしない・誰にも見せないでください。
   今回ファイルに書くのは「アカウント1つ分の秘密鍵」だけです。
   秘密鍵が漏れても被害はそのアカウント1つに限られますが、
   リカバリーフレーズが漏れると、そのウォレットの全アカウントが失われます。

▼(3) アドレスをコピーして提出する

  ウォレットができたら、そのまま続けてアドレスをご提出ください。
  主催者がテスト用の POL（テストネット専用の通貨で、換金価値はありません）をお配りします。

  1) MetaMask の画面上部に表示されているアドレス（0x で始まる文字列）をクリックすると
     コピーされます。
     （バージョンによっては、アカウントのメニュー →「アカウントの詳細」に表示されます）

  2) Slack / Discord の【要差し替え: チャンネル名】チャンネルに、
     お名前とアドレスを1行にまとめて投稿してください。

       山田太郎 0x1234567890abcdef1234567890abcdef12345678

  提出期限: 【要差し替え: 提出期限】

  ★投稿していただくのはアドレスのみです。
   アドレスは誰でも見られる公開情報なので、チャンネルに貼っても問題ありません。
   一方、秘密鍵とシークレットリカバリーフレーズ（12単語）は絶対に投稿しないでください。
   主催者からお聞きすることもありません。

▼(4) .env ファイルに秘密鍵を設定する

  プロジェクトフォルダにいることを確認してから（手順4）、実行してください。

    cp .env.example .env

  作成された .env をエディタで開きます。

    【Windows】  notepad .env
    【Mac】      open -e .env

  ※ .env は「.」で始まる隠しファイルのため、エクスプローラーや Finder には表示されません。
     上のコマンドで開いてください。

  MetaMask から秘密鍵をコピーします。
    アカウントのメニュー →「アカウントの詳細」→「秘密鍵」
    （表記は MetaMask のバージョンにより異なります。パスワードの入力を求められます）

  .env の中の SEMINAR_PRIVATE_KEY= の右側に貼り付けて、保存してください。

    SEMINAR_PRIVATE_KEY=0xあなたのセミナー専用ウォレットの秘密鍵

  .env は Git の管理対象外に設定済みです。誤って公開される心配はありません。


────────────────────────────────
よくある詰まりと対処
────────────────────────────────

・「git は認識されていません」「command not found: git」と出る
   → Git のインストール後にターミナルを開き直していません（手順2）

・「Cannot connect to the Docker daemon」と出る
   → Docker Desktop が起動していません。起動して Running になるまで待つ（手順3）

・「port is already allocated」（8545）と出る
   → 8545番ポートを使う他のアプリを終了するか、docker compose down を実行

・.env が見つからない・エクスプローラーや Finder に表示されない
   → 隠しファイルです。notepad .env / open -e .env で開いてください（手順6）

・コマンドがエラーになる／いま自分がどこにいるか分からない
   → pwd で現在地を確認。末尾が saj-web3-nft-minting でなければ cd で移動（手順4）
